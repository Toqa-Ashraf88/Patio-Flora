# 🌸 Blossom & Bloom - Flower Shop Website

A modern, fully responsive flower shop landing page and catalog built using HTML, CSS, JavaScript, and Bootstrap.

---

## 📌 Project Overview

This project is a clean, interactive website designed for a floral boutique or online flower store. It showcases various floral arrangements, offers product details, and features an intuitive, user-friendly layout optimized for both desktop and mobile devices.

---

## ✨ Features

* **Responsive Design:** Fully adapted to fit all screen sizes (Desktops, Tablets, and Mobile Phones) using Bootstrap.
* **Interactive Navigation:** Smooth scrolling and responsive navbar.
* **Product Catalog:** Beautifully formatted cards showcasing flower arrangements with pricing and details.
* **Modern UI/UX:** Clean typography, soft color palette, and engaging hover effects.
* **Contact & Order Form:** Simple layout for customer inquiries or order submissions.

---

## 🛠️ Tech Stack

* **HTML5:** Semantic structure and content.
* **CSS3:** Custom styling, layout tweaks, and animations.
* **Bootstrap 5:** Responsive grid system and styled UI components.
* **JavaScript (ES6):** Dynamic UI interactions and functional features.
